# Drafted Ovid MEDLINE strategy - ovarian cancer treatment and patient-centred outcomes
# in older adults.
#
# UNTESTED. I have no Ovid access, so unlike draft/pubmed.txt this has not been executed
# and no yields are known. It is a translation of the same concepts, written to Ovid
# conventions. Have an information specialist check it before you run it, and expect to
# adjust the .mp. field lists to your institution's Ovid configuration.
#
# Field codes used: exp = explode; / = subject heading; .mp. = multi-purpose (title,
# abstract, heading words, keywords); .ti,ab,kf. = title, abstract, author keyword;
# .fs. = floating subheading; adjN = within N words, any order.
#==============================================================================================
