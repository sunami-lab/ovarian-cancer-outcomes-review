# Complete verbatim search strategies

The `Search terms / strings` cells in `output/search_strategies.xlsx` are a **curated view**:
the outcome-relevant blocks are given in full, and long boilerplate (study-design filters,
repeated drug or population term lists) is condensed with a marker such as
`[design filter: lines 20-32]` so the cell stays readable.

For the seven reviews where that condensing happened, this directory holds the **complete,
unabbreviated strategy for every database searched** — nothing summarised, nothing
corrected, nothing translated. Use these if you intend to re-run or adapt a strategy rather
than just read it.

| File | Review | Databases covered |
|---|---|---|
| `02_mcdonald2023_cachexia-physical-function.txt` | McDonald 2023, J Cachexia Sarcopenia Muscle | Ovid MEDLINE, Embase, CENTRAL |
| `04_vita2023_antidepressants.txt` | Vita 2023, Cochrane | CENTRAL, MEDLINE Ovid, Embase Ovid, PsycINFO |
| `04_kulchycki2024_aerobic-activity-depression.txt` | Kulchycki 2024, JAMA Netw Open | Medline, Embase, Central, Cinahl, PsycInfo, Scopus |
| `06_mishra2012_hrqol.txt` | Mishra 2012, Cochrane | MEDLINE, MEDLINE In-Process, EMBASE, CINAHL, PsycINFO, PEDRO/LILACS/SIGLE/SportDiscus/OTSeeker/Sociological Abstracts |
| `06_osanto2024_hrqol-mhspc.txt` | Osanto 2024, eClinicalMedicine | PubMed, Embase (OVID), **Web of Science**, Cochrane Library |
| `07_balitsky2024_proms.txt` | Balitsky 2024, JAMA Netw Open | Medline, Embase, PsycInfo, CINAHL — original and updated search |
| `08_gomes2013_home-palliative-care.txt` | Gomes 2013, Cochrane | MEDLINE, EMBASE, CENTRAL/CDSR/DARE/HTA/NHS EED, PaPaS and EPOC registers |

The other 17 records are already complete in the workbook and need no separate file.

Each file carries a header naming the review, its DOI and the exact appendix or supplement
the text was taken from. **Typographical errors in the published strategies have been left
in place** — `qlc-c30` for QLQ-C30, `choriocrcinoma*`, `yora`, `.mp3`, and Cramer's
mis-numbered set combinations. They are flagged in the workbook cells; correct them
deliberately rather than discovering them at run time.
